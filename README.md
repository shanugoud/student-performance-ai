# AI Student Performance Predictor

A beginner-friendly Machine Learning project that predicts a student's expected final score based on academic and study-related inputs.

## Codomax Digital Solutions Internship

### Module 6 — Final AI/ML Project

## Project Overview

The AI Student Performance Predictor is a Machine Learning application built using Python and Streamlit.

The application takes student-related inputs such as:

- Study hours per day
- Attendance percentage
- Previous score
- Assignments completed
- Sleep hours per day
- Class participation percentage

The trained Machine Learning model then predicts the student's expected final score out of 100.

The application also provides a simple performance category and study advice based on the prediction.

> **Note:** This project uses a synthetic student-performance dataset created for educational purposes. It is not based on real student records.
